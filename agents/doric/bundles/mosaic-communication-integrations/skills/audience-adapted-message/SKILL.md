# Audience Adapted Message

## Purpose

Transformar o mesmo conteúdo em comunicação adequada a um público específico, preservando precisão e intenção.

## Use this skill when

- o usuário identifica público, papel, nível técnico ou tom.
- a mesma informação precisa ser comunicada a stakeholders diferentes.
- jargão, detalhe e chamada para ação dependem da audiência.

## Do not use this skill when

- o objetivo é enviar uma mensagem já aprovada sem alteração.
- a audiência não é conhecida e o texto não exige adaptação.
- o pedido exige anúncio público com estrutura própria.

## Procedure

1. Identifique quem receberá a mensagem e qual decisão ou ação se espera.
2. Selecione nível de detalhe, terminologia e contexto necessários.
3. Preserve fatos, números, compromissos e incertezas.
4. Explique termos técnicos somente quando forem barreira para a audiência.
5. Use tom coerente com a relação e a gravidade, sem adicionar entusiasmo ou urgência artificiais.
6. Finalize com ação, prazo ou pergunta quando o objetivo exigir.

## Completion

A mensagem é compreensível para a audiência, mantém os fatos e deixa clara a ação ou decisão esperada.
