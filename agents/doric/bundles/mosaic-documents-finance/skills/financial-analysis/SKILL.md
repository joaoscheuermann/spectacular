# Financial Analysis

## Purpose

Fornecer um método geral de leitura financeira que diferencia mudanças econômicas relevantes de variações superficiais.

## Use this skill when

- há demonstrações, resultados trimestrais, KPIs ou comentários de administração.
- o usuário pede interpretação do desempenho.
- é necessário entender drivers, materialidade e qualidade dos resultados.

## Do not use this skill when

- o objetivo é apenas extrair valores para uma estrutura.
- o pedido se restringe a fluxo de caixa ou rentabilidade e requer método mais específico.
- não há dados financeiros disponíveis.

## Procedure

1. Identifique período, moeda, unidade e escopo consolidado ou segmentado.
2. Compare receita, margens, custos, resultado operacional, lucro e geração de caixa conforme disponíveis.
3. Use calculator somente para métricas derivadas necessárias.
4. Separe efeitos recorrentes, sazonais e eventos não recorrentes.
5. Relacione variações quantitativas aos drivers declarados ou observáveis.
6. Destaque mudanças materiais e dados ausentes que limitam a interpretação.

## Completion

Os principais movimentos financeiros, seus drivers, sua materialidade e a limitação dominante estão explícitos.
