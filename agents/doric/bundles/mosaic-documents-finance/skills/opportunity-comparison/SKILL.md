# Opportunity Comparison

## Purpose

Estruturar comparação de oportunidades sem reduzir a decisão a uma única métrica ou ignorar restrições.

## Use this skill when

- há duas ou mais oportunidades financeiras, comerciais ou operacionais.
- o usuário quer entender qual é mais atrativa.
- as alternativas possuem benefícios e custos diferentes.

## Do not use this skill when

- o pedido exige apenas analisar uma única oportunidade.
- não existem critérios nem informação mínima para comparação.
- o usuário pede ranking explicitamente ajustado a risco, caso em que uma skill mais específica é adequada.

## Procedure

1. Defina o objetivo de comparação e as restrições obrigatórias.
2. Liste alternativas e evidências disponíveis para cada uma.
3. Compare retorno, prazo, reversibilidade, dependências e custo de oportunidade.
4. Use calculator para métricas derivadas e sort_records quando a ordenação for necessária.
5. Destaque critérios em que cada alternativa é dominante.
6. Não selecione uma vencedora se a evidência não permitir diferenciação; declare o empate ou a condição faltante.

## Completion

As oportunidades foram comparadas sob critérios comuns, seus trade-offs estão explícitos e qualquer preferência é sustentada.
