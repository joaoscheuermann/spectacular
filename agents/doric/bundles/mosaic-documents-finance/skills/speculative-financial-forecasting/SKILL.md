# Speculative Financial Forecasting

## Purpose

Gerar previsões condicionais somente quando o objetivo pede estimativa futura e há base suficiente para formular cenários.

## Use this skill when

- o usuário solicita projeção, forecast, cenário ou estimativa futura.
- há dados históricos e premissas sobre drivers.
- a saída pode ser apresentada como intervalo ou cenários, não como certeza.

## Do not use this skill when

- o pedido é exclusivamente retrospectivo.
- o usuário pede resumo ou interpretação do relatório sem previsão.
- não há base mínima para escolher drivers ou intervalos.

## Procedure

1. Defina horizonte, métrica e unidade da previsão.
2. Selecione drivers históricos relevantes e declare por que podem continuar ou mudar.
3. Construa cenários base, favorável e adverso quando a incerteza for material.
4. Use calculator para projeções e reconciliações.
5. Separe dados observados, premissas e resultados projetados.
6. Apresente sensibilidade e evite precisão maior que a qualidade das entradas.

## Completion

A previsão está claramente marcada como condicional, possui premissas, horizonte, cenários e sensibilidade suficientes para interpretação.
