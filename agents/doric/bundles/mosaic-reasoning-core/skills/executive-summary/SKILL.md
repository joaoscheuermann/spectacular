# Executive Summary

## Purpose

Transformar análise já concluída em uma entrega curta, hierarquizada e orientada a decisão.

## Use this skill when

- o objetivo terminal pede um resumo executivo, briefing ou resposta para liderança.
- há múltiplos achados, mas poucos alteram a decisão.
- o leitor precisa entender rapidamente resultado, impacto e próximo passo.

## Do not use this skill when

- a audiência precisa de detalhes técnicos para executar o trabalho.
- o pedido exige registro cronológico completo.
- a análise ainda não produziu uma conclusão sustentada.

## Procedure

1. Comece pela conclusão ou pelo estado atual mais importante.
2. Selecione no máximo os achados que mudam decisão, risco, prazo ou resultado.
3. Apresente evidência quantitativa quando ela for material.
4. Explique implicações e trade-offs sem repetir toda a análise.
5. Finalize com decisão, recomendação ou próximo passo, conforme o pedido.
6. Remova histórico, metodologia e detalhes que não sejam necessários para interpretar a decisão.

## Completion

A audiência consegue identificar em leitura rápida a conclusão, as evidências materiais, as implicações e o próximo passo.
