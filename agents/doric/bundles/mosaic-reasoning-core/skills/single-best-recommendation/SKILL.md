# Single Best Recommendation

## Purpose

Converter uma comparação suficiente em uma decisão clara sem ocultar a razão da escolha.

## Use this skill when

- o usuário pede a melhor opção, uma recomendação ou uma decisão única.
- as alternativas e os critérios relevantes já estão disponíveis.
- empates podem ser resolvidos por prioridade explícita ou premissa declarada.

## Do not use this skill when

- o usuário pediu apenas comparação sem escolha.
- a evidência é insuficiente para diferenciar alternativas.
- não existe uma alternativa claramente superior e nenhuma regra de desempate foi autorizada.

## Procedure

1. Confirme qual resultado o usuário tenta maximizar ou proteger.
2. Verifique se todas as alternativas relevantes foram comparadas.
3. Selecione a opção que melhor satisfaz os critérios prioritários.
4. Use calculator apenas para cálculos necessários à decisão.
5. Explique por que as alternativas principais ficaram abaixo.
6. Declare o trade-off dominante e a condição que poderia mudar a escolha.

## Completion

Uma alternativa é escolhida, os critérios decisivos são explícitos e a condição de reversão da recomendação está indicada.
