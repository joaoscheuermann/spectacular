# Uncertainty Reporting

## Purpose

Evitar certeza indevida e tornar visíveis as condições sob as quais uma conclusão permanece válida.

## Use this skill when

- os dados são incompletos, conflitantes, antigos ou indiretos.
- uma decisão depende de premissas que não foram verificadas.
- há mais de uma interpretação plausível.

## Do not use this skill when

- a resposta é uma transformação determinística com entradas completas.
- o usuário solicitou apenas a transcrição fiel de conteúdo.
- a limitação já foi resolvida por evidência posterior no estado.

## Procedure

1. Liste as premissas necessárias para interpretar os dados.
2. Identifique dados ausentes que poderiam mudar a conclusão.
3. Separe incerteza sobre fatos, sobre método e sobre consequências futuras.
4. Calibre a linguagem: use confiança alta somente quando a evidência for convergente e suficiente.
5. Explique o impacto prático de cada limitação relevante.
6. Não use ressalvas genéricas; relacione cada ressalva a uma parte concreta da análise.

## Completion

As principais premissas e limitações estão nomeadas, seu impacto está explicado e a confiança não excede a evidência disponível.
