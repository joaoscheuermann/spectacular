# Harness decision gates

The executable registry is `src/study/conformance.ts`. It maps every identifier
from D01 through D25 to one stable test name and one behavior check. The checks
cover catalog cardinality and references, tool/world determinism, case balance
and composition, condition isolation, hashes and PRNG, append-only traces,
paired resume behavior, baseline selection, immutable freeze, and Doric smokes.

`conformance` fails closed when an identifier, test name, or executable check
is absent. This document is an index; the TypeScript registry is authoritative.
